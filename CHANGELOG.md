# Changelog

## 1.4.0
- **Fixed:** *Open Gauge* and the Settings button in the menu bar now reliably open their window in front.
- **Fixed:** the **Gauge** app menu (Check for Updates…, Settings…, Quit) now appears at the top left whenever a Gauge window is open; Gauge returns to menu‑bar‑only when its windows are closed.
- **New:** *Check for Updates…* button in the menu bar popover.
- **New:** click an app in the popover’s top list to open it straight in the Gauge inspector.
- **New:** opt‑in high‑usage alerts (sustained CPU or memory), click to inspect.
- **New:** keyboard shortcuts in the popover (⌘O open, ⌘, settings, ⌘Q quit) and ⌘0 for the Gauge window.
- **Improved:** VoiceOver labels for overview cards, stat tiles and list rows.
- **Internal:** release gate now fails on crashed test runs, not just failed assertions.

## 1.3.0
- Launch at login, on by default (applied once from /Applications); toggle in the popover and Settings.

## 1.2.0
- CPU use cut from ≈ 50 % to ≈ 3 % with the window open (≈ 1 % menu bar only) at a 2 s refresh. Default refresh back to 2 s.

## 1.1.0
- Menu bar utility defaults (no Dock icon, Values display), Liquid Glass applied the standard way, launch‑crash fix.

## 1.0.0
- First release.
